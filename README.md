# BALLZY™ — Muga Zero-inspired editorial website

A responsive editorial/brutalist-inspired football website using oversized condensed typography, technical annotations, monochrome imagery, and a highlighter-lime accent. It is inspired by the reference image you shared, without copying Muga Zero's branding.

## Publish
Upload `index.html` and the full `assets` folder to the root of your GitHub repository. Then go to Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Before going live
- Replace the text BALLZY logo with your official custom logo file once provided.
- Replace the starter Panna visual in `assets/panna-action.png` with your own licensed/event photos.
- Verify `BALLZY_WHATSAPP_NUMBER` in `index.html`. It is currently `919748236905`, based on a previously supplied number, and must be confirmed.
- Set `BALLZY_REGISTRATION_EMAIL` if you want the visitor's email app to open as well. Both WhatsApp and email require the visitor to tap Send.
- This static form does not automatically store registrations or silently send data.
